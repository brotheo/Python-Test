PART 2 · 25–40 min

Changing lists

Lists are mutable: they can change after you make them
CodeWhat it does
colours[1] = "yellow"Replace the item at index 1
colours.append("purple")Add to the end
colours.insert(0, "black")Add at index 0, pushing the rest along
colours.remove("red")Remove the first item equal to that value
colours.pop() / colours.pop(0)Remove and return the last item / the item at index 0
sorted(nums) / nums.sort()Return a new sorted list / sort the list itself
sum · min · max · in · .count() · .index()Total, smallest, largest, is it there?, how many times, where is it?

PART 3 · 40–50 min

Looping and algorithms

Two ways to loop, four algorithms to know
# 1. Loop over the VALUES
for t in temps:
    print(t)
# 2. Loop over the INDEXES
for i in range(len(temps)):
    print("Day", i + 1, temps[i])

Use loop 2 when you need the position, for example "which day was hottest?"
