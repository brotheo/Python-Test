Learning objectives

  1. LO1 Create a list and read items by index, negative index and slice
  2. LO2 Change a list with append, insert, remove, pop and index assignment
  3. LO3 Loop through a list by value and by index
  4. LO4 Write totalling, counting, max/min and linear search on a list
  5. LO5 Choose between a list, tuple, set and dictionary

Prior knowledge: variables, input/output, if, for/range and while loops. Key words: list, element, index, zero-indexed, slice, mutable, immutable, tuple, set, dictionary, key, value, IndexError.

PART 1 · 10–25 min

Indexing and slicing

Talking points and answers
  • The index is the distance from the start, so the first item is 0 steps away.
  • Negative indexes count from the end: -1 is always the last item.
  • A slice [a:b] includes a and stops before b, like range.

Quick check: x[0] 10 · x[-1] 50 · x[1:3] [20, 30] · len(x) 5

MCQ: B · 9

Make them do itHave the student type print(fruits[4]) into the demo box and read the IndexError aloud. Seeing the error once sticks better than being told.
PART 2 · 25–40 min

Changing lists

Talking points and answers

Colours trace: final colours ['yellow', 'blue'] · last 'purple' · first 'black'

True or false: 1 F · 2 T · 3 T · 4 F · 5 T

Order mattersInsist the student types their predictions before pressing Next line on the step-through. The stepper is the check, not the lesson.
Misconceptionremove(0) looks for the value 0, not index 0. Use pop(0) to remove by index.
PART 3 · 40–50 min

Looping and algorithms

Talking points and answers

Gaps: temps[0] · if t > highest · highest = t

Why temps[0] and not 0? If every value is negative, starting at 0 would output 0, a value that is not in the list.

Exam linkExams often ask for totalling, counting, max/min and linear search without built-in functions. Make sure the student can write each one by hand.
PART 4 · 50–58 min

Other collections

Talking points and answers

Uncommented tuple line gives TypeError: 'tuple' object does not support item assignment.

Which collection? coordinates Tuple · different countries Set · mark by name Dict · to-do list List

Ask"Why is a dictionary faster than searching a list for a name?" You go straight to the key, with no loop.

TEACHER VS STUDENT · 80–85 min

Your live-coding round

Solve these while thinking aloud. The student scores a point for each slip they catch.
  1. T1. Second largest distinct value in [7, 3, 9, 9, 4] in one pass, with no sorting. Answer 7.
  2. T2. Rotate right: [1, 2, 3, 4] → [4, 1, 2, 3], by slicing, then by pop + insert.
  3. T3. One bubble-sort pass on [5, 1, 4, 2], printing after each swap.
  4. T4. Student's revenge: the student hides one bug in a 5-line program, and you get 60 seconds.
